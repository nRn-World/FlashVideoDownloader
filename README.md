<p align="center">
  <b>A sleek, modern, high-performance video downloader extension for Google Chrome.</b><br>
  Built with Manifest V3, turbo multi-threaded HLS merging engine, live duration tracking, and multi-language support.
</p>

---

## ✨ Features

- **🌐 Deep Network Sniffing**: Automatically intercepts and detects media streams across the web (MP4, WEBM, FLV, M3U8, TS, MOV, MKV, MP3, etc.).
- **⏱️ Live Duration & Progress Tracking**: See total video duration before downloading, and track elapsed vs total duration in real-time during downloads.
- **⚡ Turbo HLS Downloader Engine**: Download complete multi-hour HLS (`.m3u8`) streams with 20 parallel threads merged directly into high-quality `.mp4`.
- **🔄 Background Downloads**: Downloads run persistently in the background service worker — even if you close the popup or switch tabs.
- **▶️ In-App Preview Player**: Preview detected videos directly in the extension popup before initiating download.
- **🌍 Multi-Language Support**:
  - English (Default)
  - Svenska (Swedish)
  - Türkçe (Turkish)
  - Español (Spanish)
  - Français (French)
  - العربية (Arabic)
- **📜 Download History & Auto-Clean**: View your recent download history with auto-deletion after 24 hours (configurable in Settings).

---

## 🚀 Installation Guide

1. Clone or download this repository:
   ```bash
   git clone https://github.com/nRn-World/FlashVideoDownloader.git
   ```
2. Open **Google Chrome** and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the folder `Flash Video Downloader`.
6. Pin the extension to your toolbar and enjoy!
